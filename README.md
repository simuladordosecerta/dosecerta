# 💉 Dose Certa - Calculadora e Simulador de Seringa

Uma ferramenta web interativa para cálculo de doses de vias subcutânea (SC) e intramuscular (IM), conversão de unidades e simulação visual de seringas com gráficos de picos plasmáticos.

## 🚀 Funcionalidades
- **Simulador Visual Realista de Seringas**: Compatível com seringas normais e de insulina (UI).
- **Cálculo Automático**: Conversão entre mg/ml e UI.
- **Cronograma de Aplicações**: Projeções detalhadas para 7, 15 e 30 dias.
- **Gráfico de Picos Plasmáticos**: Acompanhamento visual da variação estimada ao longo de 14 dias.
- **Exportação em PDF**: Pronto para salvamento e impressão dos resultados.

## 🌐 Acesso Online via GitHub Pages
Este repositório está configurado para o GitHub Pages. Você pode acessar a aplicação diretamente pelo navegador assim que ativar o serviço nas configurações do repositório (`Settings > Pages > Source: main`).

## 🛠️ Tecnologias Utilizadas
- HTML5 / CSS3
- Tailwind CSS (via CDN)
- Chart.js (para gráficos)
- FontAwesome (para ícones)
